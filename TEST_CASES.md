# Тест-кейсы wilson.com

Составлены по замечаниям ментора. Спеки организованы по компонентам: **main menu**, **footer**, **chat online**, **announcement bar**.

Общие правила:
- Предусловие для всех кейсов: куки приняты (`cy.acceptCookies()`), открыта главная страница.
- Проверки URL не используем — результат проверяем по контенту на странице.
- Каждый тест атомарный: одно действие → одна проверяемая цель.
- Названия тестов (`it`) — на английском.

## 1. `main-menu.spec.cy.ts` — правое меню хедера

### MM-01 · `opens the account menu`
Бывший `opens the account popup`. Все пять проверок — через soft assert, чтобы тест показал все отсутствующие элементы сразу, а не падал на первом.

| Шаг | Ожидаемый результат |
|---|---|
| 1. Нажать на иконку аккаунта | Открылось меню аккаунта |
| 2. Проверить содержимое меню | Видны все 5 элементов: **Orders**, **Profile**, **Legacy Orders**, заголовок **Sign in or create account**, поле ввода **email** |

### MM-02 · `shows the search dialog content`
Проверка контента окна поиска.

| Шаг | Ожидаемый результат |
|---|---|
| 1. Нажать на иконку поиска (лупа) | Открылось окно поиска |
| 2. Проверить содержимое окна | Видны: поле ввода поиска, блок **Popular searches**, блок **Popular products** |

### MM-03 · `shows search results matching the query`
Проверка работы поиска — товары подгружаются прямо в окне поиска во время ввода, **без нажатия Enter**.

| Шаг | Ожидаемый результат |
|---|---|
| 1. Нажать на иконку поиска | Открылось окно поиска |
| 2. Ввести запрос `duffle`, **Enter не нажимать** | В поле поиска `duffle`, блок товаров сменил заголовок с **Popular Products** на **Product Matches** |
| 3. Проверить каждый товар в блоке | **Каждый** товар содержит в названии `Duffle` |

> В записях встречаются два запроса: `rackets` и «дафл». В итоговых шагах указан «дафл», поэтому взят `duffle`.
> Проверяем одно написание `Duffle`. Поиск находит и написание «Duffel» — если такой товар попадёт в подсказки, тест упадёт, и проверку нужно будет расширить.

> С Enter открывается отдельная страница результатов (22 товара). Там последним выдаётся **Lettuce-Edge Quarter Sock** (носки), в названии нет ни `duffle`, ни `duffel`. В подсказках без Enter (4 товара) носков нет. Стоит показать ментору как возможный баг релевантности поиска.

Бывший `need-help.spec.cy.ts`. Ссылки проверяем кликом и переходом на нужную страницу, тесты параметризованы: одна функция → по тесту на каждую ссылку из списка.

### FT-01 · `opens the contact us page`
| Шаг | Ожидаемый результат |
|---|---|
| 1. Нажать **Contact Us** в блоке Need Help | Открылась страница Help Center |
| 2. Проверить заголовок страницы | Виден заголовок **Help Center & Contact Us** |
| 3. Проверить блоки быстрых действий | Видны 3 блока: **Limited Warranty Request**, **Start a Return**, **View Gift Card Balance** |

### FT-02 · `opens the <link> page from the footer` (параметризованный)
Внутренние ссылки футера:

| Колонка | Ссылка | Ожидаемый результат после клика — виден текст |
|---|---|---|
| Our Company | About Us | **Creating a Better World Through Sport** |
| Our Company | Stores & Dealers | **Experience a Wilson Retail Store** |
| Our Company | Careers | **Wilson Careers** |
| Resources | Check Gift Card Balance | **Enter a gift card number and PIN** |
| Promotions & Discounts | Military Discount | **Military Discount** |

Шаги для каждой строки:
1. Нажать ссылку в нужной колонке футера.
2. Проверить, что открылась нужная страница — по заголовку или ключевому элементу страницы.

> About Us в Cypress открывается в той же вкладке, обход не нужен.
> Внешние ссылки (Our Sites, Start a Return, Tax Exempt и т.д.) ведут на другие домены — в первую итерацию не берём.

## 4. `announcement-bar.spec.cy.ts` — чёрная полоса сверху

### AB-01 · `shows the announcement bar content`

| 1. Проверить полосу на главной | Видны текст **Get 15% Off First Purchase** и ссылки **Chat Online**, **Find a Store** |

### AB-02 · `opens the first purchase discount offer` · 🐞 известный баг
| Шаг | Ожидаемый результат |
|---|---|
| 1. Нажать **Get 15% Off First Purchase** | Открылось окно с предложением скидки (подписка на рассылку) |

**Фактический результат:** клик ничего не открывает.

**Вероятная причина:** у ссылки `href="javascript:void(0)"`, окно открывает скрипт сайта по id `announcement_promo`. В id попали типографские кавычки: `id="“announcement_promo”"`, поэтому скрипт не находит ссылку.

**В коде:** тест пишется через `it.skip` с комментарием про баг. Когда сайт исправят — убрать `.skip`.

## Изменения во фреймворке (не тест-кейсы)

- `HomePage` экспортировать сразу объектом (`export const homePage = new HomePage()`), а не классом.
- Удалить `home.spec.cy.ts`: проверка «страница открылась» не стоит открытия браузера.
- Переименовать: `top-right-menu.spec` → `main-menu.spec`, `need-help.spec` → `footer.spec`, `chatWindow` → `chatDialog`, account popup → account menu.
- Убрать все проверки URL, заменить проверками контента.
- Установить плагин soft assert для Cypress (для MM-01).
- Запускать `cypress run --headed --browser chrome`, чтобы сайт не блокировал headless-режим.
